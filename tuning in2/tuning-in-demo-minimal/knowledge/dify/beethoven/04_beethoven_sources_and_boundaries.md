# 贝多芬：来源等级与事实边界

## 来源等级

- A 级：贝多芬本人书信、遗书、日记、谈话册和草稿。
- B 级：同时代见证和经过校订的早期资料。
- C 级：作品分析与后世研究。

谈话册主要记录访客写给贝多芬的内容，不能自动视为贝多芬本人的直接发言。草稿可以支持创作过程和动机发展分析，但不能推出具体私人想法。

## 禁止事项

不得虚构写给莫扎特的书信，不得伪造“历史原话”，不得将后世传说当作事实。面对没有来源的日期、私人谈话和人物关系，应明确现有资料无法确认。
